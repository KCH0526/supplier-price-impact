# 產品決策紀錄：供應商漲價與客戶報價毛利風險覆核器

英文名稱：Supplier Quote Margin Guard
決策日期：2026-11-03　｜　狀態：技術 MVP 開發中，商業價值尚未經真實客戶驗證

## 1. 決策

在既有的「供應商漲價成本試算」上，加上第三份 Excel：**客戶未結報價（OpenQuotes）**。
產品回答一個問題：

> 供應商漲價後，哪些**仍有效的客戶報價**毛利率會低於公司設定的底線？要把報價調到多少才能回到底線？

產品只產生**需人工覆核**的報告。它不修改 ERP、不調整或寄送客戶報價、
不判斷客戶是否會接受漲價，也不主張企業有權向客戶追價差。

## 2. 四個角色的獨立審查

| 角色 | 最重要的產品價值 | 最可能失敗的假設 | 必須拒絕的功能 | 最小可收費版本 |
|---|---|---|---|---|
| A. 台灣製造業 ERP 顧問 | 把「供應商調價」接到「客戶報價」，以前需要跨採購、成本、業務三方手工比對 | 中小企業能在合理時間內匯出**單階已展開** BOM、人工製費與未結報價 | ERP 寫回、多階 BOM 展開、自動換匯換單位 | 一次欄位對應＋一份可追溯的覆核報告 |
| B. B2B 產品經理 | 業務主管拿到一份依風險排序、每列都附理由的覆核清單 | 主管會為「覆核前的預警」付費，而不是只在 ERP 改價後才處理 | 自動發信、LINE 通知、訂閱帳務、登入系統 | 首次欄位對應＋報告（待測價格 NT$3,000～8,000） |
| C. Python 技術負責人 | 現有成本引擎（Decimal、阻擋例外、逐行稽核）已通過參考答案驗收，只需在後面加一層 | 報價數量與完整成本口徑在不同企業定義不一致 | 重寫成本引擎、資料庫、多租戶 | 三份 Excel → 一份 xlsx，本機或內網 Docker |
| D. 反對派／資訊安全 | 資料只在記憶體處理，不外傳 | 企業願意把成本與客戶報價放進任何外部工具 | 公開 Demo 使用真實資料；把情境金額說成實際損失 | 只在本機或客戶內網執行 |

### 交叉質疑與結論

- **D 質疑 B**：「報價情境成本增加」容易被讀成「公司會損失的錢」。
  → 報告和 UI 一律標示「依報價數量推估的情境金額」，並註明不是已確認訂單或實際損失。
- **A 質疑 C**：完整成本缺人工或製費時，毛利率沒有意義。
  → 沿用既有規則：成本不完整就標「無法可靠判斷」，不顯示毛利數字，也不把缺少的成本當成 0。
- **C 質疑 A**：報價可能是外幣或含小數數量。
  → MVP 只接受 TWD 與整數件數，其他一律阻擋，不猜匯率、不猜換算係數。
- **D 質疑全體**：「維持底線所需單價」可能被當成建議售價直接報給客戶。
  → 欄位名稱固定為「維持底線所需最低單價」，狀態一律寫「需人工覆核」，並以無條件進位避免低估。
- **B 質疑 D**：沒有雲端版是否就賣不出去？
  → 先賣「顧問陪同的單次試算服務」，雲端版延後到有付費意願的證據之後。

計算規則沒有發現會讓結果不成立的重大缺陷，所以維持「客戶報價毛利風險覆核」這個方向。

## 3. 事實、推論與假設

### 已由資料證實的事實（僅限本 repo 的合成資料）

- 以 2026-12-01 為試算日，六款成品的完整成本與 `tests/fixtures/expected_result_reference.xlsx` 一致，
  例如 P-1001 從 836.60 變為 872.20，月成本增加合計 61,597.00。
- 阻擋例外（重複報價、單位或幣別不一致、未核准 BOM 等）會讓成品標示為不完整，不會被低估成較小的數字。
- 案例 A（P-1001，售價 1000、數量 50、底線 15%）的預期結果：
  原毛利率 16.34%、新毛利率 12.78%、維持底線最低單價 1026.12，需人工覆核。

### 產品推論（合理但未驗證）

- 少量多樣的製造業常有仍在有效期間內的客戶報價，供應商調價會直接侵蝕這些報價的毛利。
- 業務主管需要的是依風險排序、附有原因的清單，而不是另一份成本表。

### 尚未驗證的商業假設

- 目標企業能在 60 分鐘內完成三份 Excel 的欄位對應。
- 企業願意為單次試算付費；NT$3,000～8,000 這個價格區間是待測價格，不是成交價。
- 企業願意提供經授權、已去識別化的資料。
- 市場上已有 ERP 內建模組、BI 工具與顧問服務可做類似分析。
  本產品**沒有**宣稱市場上沒有競爭者；差異只在於「改 ERP 之前、以三份 Excel 做可稽核的覆核」。

## 4. 不做的事（本階段）

登入系統、金流、訂閱帳務、多租戶資料庫、ERP 寫回 API、自動寄送 Email、LINE 通知、
OCR、多階 BOM 引擎、ECN 呆滯損失計算、自動調整或發送客戶報價。
