# 成本與流量預估表

所有數字都要由使用者向各服務商查證後再填寫，本表只列出費用來源。**沒有任何流量或收入的實際資料。**

## 費用

| 項目 | 是否必要 | 費用來源 | 金額（待填） |
|---|---|---|---|
| 網域 | 必要（若使用自有網域） | 網域註冊商的年費公告 | |
| 靜態網站託管 | 必要 | GitHub Pages、Cloudflare Pages、Netlify 等的免費額度與付費方案 | |
| 電子郵件（聯絡用） | 建議 | 郵件服務商的方案 | |
| 法律審閱（隱私、條款、合約） | 收費前必要 | 律師或法務顧問報價 | |
| 雲端訂閱版主機、資料庫、備份 | 目前不需要（延期） | 雲端平台計價 | |
