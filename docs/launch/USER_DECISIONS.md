# 使用者決策清單

以下事項需要你決定，並**明確授權**之後才會執行。本專案沒有購買網域、註冊服務、部署網站或建立任何帳戶。

| # | 決策 | 選項／說明 | 費用來源 | 你的決定 |
|---|---|---|---|---|
| 1 | 是否公開部署靜態網站 | 是／暫不 | — | |
| 2 | 網域 | 自有網域（`.tw`、`.com.tw`、`.com`）或託管平台提供的子網域 | 註冊商年費 | |
| 3 | 託管平台 | GitHub Pages、Cloudflare Pages、Netlify、公司主機 | 各平台方案 | |
| 4 | 聯絡方式 | 公開的電子郵件或電話 | 郵件服務方案 | |
| 5 | 法律文件審閱 | 隱私權政策、服務條款、資料保存政策 | 律師或法務顧問報價 | |
| 6 | 廣告帳戶 | 是否申請 AdSense（需先完成 `ADS_REVIEW_CHECKLIST.md`） | 不保證核准 | |
| 7 | 是否使用網站分析工具 | 使用前需更新隱私權政策 | 依工具 | |
| 8 | 金流方式 | 導入服務的收款方式（例如轉帳、開立發票）；不需要網站金流 | 依銀行或服務商 | |
| 9 | 試用客戶的聯絡管道 | 介紹、展覽、既有人脈（不寄陌生開發訊息） | — | |
| 10 | GitHub 分支保護 | 必要檢查 `test`、禁止 force push | 免費 | |

收到明確授權之前，所有對外發布或會產生費用的操作都不會執行。
