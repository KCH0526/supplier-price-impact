# 廣告導入審查清單

目前網站**沒有**任何廣告程式碼，也沒有預先放入任何廣告帳戶資訊。廣告只是潛在的輔助收入，不列入收入預估，也**不保證** Google 會核准。

## 申請前（全部完成才申請）
- [ ] 使用者決定要申請，並自行建立廣告帳戶（本專案不代為註冊）。
- [ ] 隱私權政策經專業審閱，並已加入第三方 cookie 與退出方式的說明。
- [ ] 確認是否有歐洲經濟區、英國、瑞士的使用者；如有，依 Google 最新政策使用經認證的同意管理平台。
- [ ] 原創內容足夠，教學文章持續更新，沒有大量空泛頁面。
- [ ] 網站已在正式網域上線，可以正常瀏覽。
- [ ] 依 Google 官方最新的計畫政策逐項檢查（以官方網站為準）。

## 版位規則
- [ ] **不在**免費工具頁、Demo 頁、任何未來可能處理企業資料的頁面放廣告。
- [ ] 只在教學文章等內容頁考慮放置，不能遮住內容，也不能讓人誤以為是網站本身的按鈕。

## 禁止事項
- [ ] 不自行點擊廣告、不請他人點擊、不使用虛假的瀏覽量或點擊。
- [ ] 不宣稱放了廣告就能立即獲得收益。
- [ ] 加入廣告後，重新執行測試，並更新 `tests/test_web_site.py` 中與追蹤程式相關的規則（需要人工決定）。
