# 服務內容與限制（草案，待市場驗證）

> 本文件是**服務構想草案**，不是合約。正式合作前，條款需經法律專業人士審閱。
> 示範與文件中的資料全部是合成資料。目前沒有任何成交或客戶使用紀錄。

## 單次「毛利風險試算」服務（構想）

| 項目 | 內容 |
|---|---|
| 範圍 | 一個工廠、一次供應商調價通知、最多 50 張有效客戶報價 |
| 客戶提供 | 經授權、已去識別化的三份 Excel（見 `CUSTOMER_ONBOARDING.md`） |
| 服務方提供 | 欄位對應（約 60 分鐘）、一份 `result.xlsx`、30 分鐘報告說明 |
| 執行環境 | 客戶電腦或客戶內網優先；若在服務方電腦處理，需書面同意並約定刪除期限 |
| 交付後 | 依約定刪除資料，並以書面回報 |
| 待測價格 | NT$3,000～8,000／次（**待市場驗證的假設，不是已證明的定價**） |

## 不包含

- 寫回 ERP、修改客戶報價、通知或寄信給客戶
- 匯率換算、單位換算、每百件或階梯價格換算（需由客戶先在 Excel 處理）
- 多階 BOM 展開、多工廠或多版本成本
- 判斷客戶是否會接受漲價，或提供法律、合約建議

## 不保證

- 結果等同 ERP 正式標準成本或會計數字
- 「報價情境成本增加」等於實際損失；它只是依報價數量推估的情境金額
- 「維持底線所需最低單價」可以被客戶接受
- 可以直接讀取任何 ERP 的原生匯出檔

## 結果的使用方式

報告只供企業內部**人工覆核**。是否調整報價、如何與客戶溝通，都由企業自行決定並承擔。
