# 客戶導入流程（Customer Onboarding）

目標：用客戶授權、已去識別化的資料，在**一次會議（目標 60 分鐘內）**完成欄位對應，
產出第一份經人工驗算的毛利風險報告。

## 1. 客戶需要提供的三份 Excel

| 檔案 | 最少內容 | 常見 ERP 來源（僅為舉例，實際依客戶系統而定） |
|---|---|---|
| ① BOM／成本 | 成品、子件、每件用量、原單價；另附每件人工、製費、其他成本 | 產品結構、標準成本表、成本計算報表 |
| ② 供應商調價 | 料號、單位、幣別、新單價、生效日、供應商 | 採購詢價、供應商報價單、調價通知 |
| ③ 客戶未結報價 | 報價單號、行號、成品、客戶、未稅單價、數量、有效期間、狀態 | 業務報價單、報價明細 |

範圍建議：先挑**一個工廠、一次調價通知、20～50 張有效報價**。不要一開始就匯出整個 ERP。

## 2. 去識別化

在客戶端完成以下處理後才交付檔案：

- 客戶名稱 → 刪除；客戶代碼 → 改成代號（例如 C-001），對照表留在客戶端。
- 供應商名稱 → 刪除；供應商代碼可保留或改代號。
- 成品、料號名稱 → 可改成類別描述（例如「鋁擠型」），料號可保留或改代號。
- 單價、用量、成本**不要**改動，否則驗算沒有意義。
- 刪除與計算無關的欄位（聯絡人、地址、付款條件、備註）。

## 3. 確認資料授權

開始前取得客戶書面確認（Email 即可），內容至少包括：

1. 提供者有權提供這些資料，用途限於本次欄位對應與試算。
2. 資料存放位置：只在客戶電腦或客戶內網執行本工具；若需在服務方電腦處理，需明確同意並約定刪除時間。
3. 結束後刪除方式與期限（例如交付報告後 7 天內刪除，並以 Email 回報）。
4. 報告僅供內部決策參考，不代表服務方保證任何成本或價格結論。

未取得授權前，只使用 `samples/` 的合成資料示範。

## 4. 欄位對應

1. 打開客戶的匯出檔與 README 第 7 節，逐欄填寫下表。
2. 欄位名稱不同時，用工具的「Excel 欄位對應」頁逐欄指定，並下載 `field_mapping.json` 留存，作為本次對應的紀錄。
   單位、幣別、每批用量等需要**換算**的欄位，工具不會代為處理，請先在 Excel 新增一欄計算，並**貼成值**。
3. 先只轉 5～10 列，上傳確認沒有讀取錯誤，再處理全部資料。

| 客戶欄位名稱 | 本工具欄位 | 轉換方式 | 確認人 |
|---|---|---|---|
| （例）品號 | 成品編號 | 直接改名 | |
| （例）報價有效迄日 | 截止日 | 改名；確認是日期格式 | |
| （例）狀態 = 「已核准」 | 報價狀態 = 「有效」 | 建立對照表 | |

常見陷阱：

- 料號被 Excel 轉成數字，前導零消失 → 匯出時設成文字欄。
- 用量是「每批 100 件」 → 先除以批量，或填 BOM基準產量讓系統阻擋提醒。
- 報價是「每百件」或 USD → 本工具不換算，要先人工轉成每件 TWD，並記錄依據。
- 報價狀態文字不同 → 先建對照表，只有確認有效的報價轉成「有效」。

## 5. 確認成本口徑

在報告產出前，請客戶成本負責人書面回答：

| 問題 | 選項 |
|---|---|
| 原單價代表什麼？ | 標準成本／最近進價／移動平均／其他 |
| 人工、製費從哪裡來？ | 標準成本表／實際分攤／估計 |
| 是每件成本嗎？ | 是／否（否則先換算） |
| 客戶報價是否未稅、TWD、每件？ | 是／否 |
| 毛利率底線是多少？ | 例如 15%；不同客戶群是否不同 |

答案寫進報告的交付說明。口徑沒有確認前，不要讓客戶用報告做決定。

## 6. 人工驗收與簽核

1. 執行本工具，下載 `result.xlsx`。
2. 由客戶成本會計**手算 3 個成品**的原、新成本，並與 Cost Impact 比對。
3. 由業務主管**手算 3 筆報價**的新毛利率與最低單價，並與 Quote Risk 比對。
4. 逐筆說明 Exceptions、Quote Exceptions 中的阻擋例外，確認是資料問題還是規則需要調整。
5. 雙方簽核以下表格：

| 項目 | 結果 | 簽核人／日期 |
|---|---|---|
| 欄位對應表確認 | | |
| 成本口徑確認 | | |
| 3 個成品手算一致 | | |
| 3 筆報價手算一致 | | |
| 阻擋例外已說明 | | |
| 報告僅供人工覆核，不代表自動調價建議 | | |

6. 依授權約定刪除資料，並回報刪除完成。

## 7. 報價工作台（批次成本）導入補充

- 請客戶提供每件變動成本（材料、人工、製費、委外），以及每批固定費（開機、換線治具、其他）的明細，並確認口徑。
- 確認既有 ProductCost 是否已包含批次費。若無法確認，只能使用「既有完整單件成本」模式，而且**不可另加批次費**。
- 和客戶確認 MOQ 與常用的報價數量級距。
- 客戶草稿由客戶權責人員填價並確認；服務方不代為決定售價。
