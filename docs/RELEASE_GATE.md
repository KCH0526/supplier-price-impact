## 3. 尚未驗證

- 不傳入 CA、在一般網路（沒有 SSL 檢查 proxy）用原始 Dockerfile 建置
- Windows／macOS Docker Desktop、客戶的內網伺服器
- HTTPS 反向代理與存取控制
- 在客戶實際硬體上的效能，以及多人同時處理大檔
- 真實 ERP 匯出檔的欄位、單位與狀態文字
- 第一次使用的人能否不經說明就完成操作
- 歷史報價比較門檻（0.5～2 倍、730 天、3 筆、30%）是否符合真實客戶的習慣
- 真實的歷史報價檔格式與資料品質
