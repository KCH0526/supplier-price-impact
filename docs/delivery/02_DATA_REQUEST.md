# 2. 三份 ERP 匯出資料需求表

請依下表匯出 Excel（.xlsx）。欄位名稱不必和下表相同，之後會逐欄對應。
識別碼欄位（料號、成品編號、客戶代碼、報價單號）請設定為**文字格式**後再匯出，以免前導零遺失。

## ① BOM 與成本

| 需要的資料 | 必要 | 說明 | 常見 ERP 來源（僅為舉例） |
|---|---|---|---|
| 成品編號、成品名稱 | 是 | | 品號主檔 |
| 子件料號、子件名稱 | 是 | 已展開到最底層的採購材料 | 產品結構（BOM） |
| 單位 | 是 | 要和供應商報價的單位一致 | |
| 每件成品用量 | 是 | 若是「每批 N 件」的用量，請另外提供批量 | |
| 原單價 | 是 | TWD、每 1 單位；請說明是標準成本、最近進價或移動平均 | 成本表、採購單價 |
| 每件人工、製造費用、其他成本 | 計算毛利率時需要 | 每件成品的金額 | 標準成本表 |
| 工廠、BOM 版本、BOM 狀態、有效期間、供應商 | 建議提供 | 用來檢查範圍是否一致 | |

## ② 供應商調價

| 需要的資料 | 必要 | 說明 |
|---|---|---|
| 料號、品名、單位 | 是 | |
| 幣別 | 是 | 只接受 TWD；外幣請先換算，並註明採用的匯率與日期 |
| 新單價 | 是 | 每 1 單位；若是每百件的價格，請先換算或提供計價數量 |
| 生效日 | 是 | |
| 供應商、工廠、失效日、核准狀態 | 建議提供 | |

## ③ 客戶未結報價

| 需要的資料 | 必要 | 說明 |
|---|---|---|
| 報價單號、行號 | 是 | 合起來必須唯一 |
| 成品編號、客戶代碼 | 是 | 客戶代碼請先改為代號（見 03） |
| 未稅單價、幣別 | 是 | TWD、每件 |
| 報價數量 | 是 | 整數件數 |
| 生效日、截止日 | 是 | |
| 報價狀態 | 是 | 請另外提供狀態文字的意義，例如哪些狀態代表仍然有效 |

## 範圍建議

只匯出本次需要的資料：一個工廠、受本次調價影響的成品，以及仍有效的報價。不需要匯出整個 ERP。
