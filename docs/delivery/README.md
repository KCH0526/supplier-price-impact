# 客戶交付工具包

一次「毛利風險試算」從接洽到資料清除所需的全部文件。範例與示範都使用合成資料。

> 涉及合約、授權、資料保護的文件都只是**草案**，正式使用前需經法律專業人士審閱。
> 價格是**待市場驗證的假設**。
