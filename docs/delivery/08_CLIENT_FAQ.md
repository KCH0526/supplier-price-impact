# 8. 常見客戶問題

**Q1：你們能直接讀我們 ERP 的檔案嗎？**
不能保證。工具有「Excel 欄位對應」頁，可以把不同的欄位名稱逐欄對應到標準格式；但我們沒有宣稱支援任何 ERP 的原生格式，也沒有取得任何 ERP 廠商的認證。需要用您的去識別化樣本實際試過才知道。

**Q2：資料會傳到哪裡？**
工具在您的電腦或公司內網執行，上傳的檔案只在記憶體中處理，不寫入磁碟，並已關閉使用統計。若需要在我們的電腦處理，會先取得您的書面同意，並約定刪除期限。

**Q3：算出來的「最低單價」可以直接報給客戶嗎？**
不建議。它只是「新成本 ÷（1 − 毛利底線）」的計算結果，沒有考慮客戶關係、合約與市場行情。

**Q4：情境成本增加是我們會損失的錢嗎？**
不是。它是「每件成本增加 × 報價數量」的推估金額。報價不一定成交，數量也可能改變。

**Q5：為什麼有些報價沒有毛利率？**
報價或成本資料有問題，例如空白、外幣、成本不完整。工具寧可不給數字，也不給可能錯誤的數字；每一筆都會寫出原因。

**Q6：可以處理多階 BOM、外幣、每百件報價嗎？**
目前不行，需要先在 Excel 換算成單階、TWD、每件。工具不會自行猜測換算方式。

**Q7：多久可以拿到報告？**
資料與成本口徑都確認之後，通常一次會議內就能產出；整個流程的實際時間，要看資料準備的情況。

**Q8：價格是多少？**
目前規劃單次 NT$3,000～8,000，這是還在測試中的價格。範圍見《服務範圍》（07）。

**Q9：之後每次漲價都要重新付費嗎？**
可以沿用第一次確認的欄位對應設定，重跑會比較快。定期服務的內容與價格仍在規劃中。

**Q10：你們有其他客戶在用嗎？**
目前還沒有。工具只用合成資料完成驗收，您可能是最早試用的企業之一。
