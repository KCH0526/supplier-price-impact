# 9. 交付後資料清除說明（草案）

> 本文件為**草案**。實際的保存期限與刪除方式，請依雙方約定及法律專業人士審閱的條款執行。

## 工具本身會保存什麼

| 項目 | 說明 |
|---|---|
| 上傳的 Excel | 只在伺服器記憶體中處理，不寫入磁碟；關閉頁面或重啟服務後就會消失 |
| 產生的報告 | 只存在工作階段記憶體，直到使用者下載；伺服器不保存 |
| 使用紀錄 | 工具不保留歷史紀錄；Streamlit 的使用統計已關閉 |
| 終端機 log | 只記錄服務啟動與錯誤訊息，不記錄檔案內容 |

## 需要人工清除的地方

| 位置 | 清除方式 | 完成 |
|---|---|---|
| 下載資料夾中的 `result.xlsx`、`standardized.xlsx` | 刪除並清空資源回收筒 | ☐ |
| 客戶提供的原始 Excel（Email 附件、雲端硬碟、隨身碟） | 刪除所有副本 | ☐ |
| `field_mapping.json` | 只含欄位名稱；依約定決定保留或刪除 | ☐ |
| 會議紀錄、截圖 | 確認不含客戶資料，或一併刪除 | ☐ |
| 若曾在服務方電腦執行 | 停止服務；Docker 執行 `docker compose down` | ☐ |
