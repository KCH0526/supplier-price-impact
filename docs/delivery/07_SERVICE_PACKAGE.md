# 7. 單次試算服務範圍與初期報價方案（草案）

> 本文件為服務構想**草案**，不是合約。正式合作前，條款需經法律專業人士審閱。
> 目前沒有任何成交或客戶使用紀錄。

## 單次「毛利風險試算」

| 項目 | 內容 |
|---|---|
| 範圍 | 一個工廠、一次供應商調價通知、50 張以內的有效客戶報價 |
| 包含 | 30 分鐘訪談與展示；欄位對應（目標 60 分鐘）；一份 `result.xlsx`；人工驗收陪同；30 分鐘報告說明 |
| 客戶負責 | 資料授權、去識別化、匯出三份 Excel、確認成本口徑、最終決策 |
| 執行地點 | 客戶電腦或內網優先 |
| 交付期限（構想） | 收到完整資料後 5 個工作天內 |

## 初期報價方案

| 方案 | 價格 | 內容 |
|---|---|---|
| 單次試算 | NT$3,000～8,000／次（待市場驗證的假設價格） | 上述範圍 |
| 後續定期覆核（構想） | NT$1,000～3,000／月（待驗證） | 沿用已確認的欄位對應，每次調價重跑 |

- 以上價格**並非**已成交、也**不是**已被市場證明的價格，只是用來在訪談中測試客戶的反應。
- 範圍外的工作（多工廠、超過 50 張報價、需要先整理大量資料）另行估價。

## 不包含

- 寫回 ERP、修改或寄送客戶報價、通知客戶
- 匯率、單位、每百件、階梯價格的換算
- 多階 BOM 展開
- 法律、稅務、合約建議
- 保證客戶接受新價格、保證減少損失

## 付款與取消（待專業人士審閱後再定）

付款時點、取消、退費、責任上限、保密義務等條款，都需要由法律專業人士審閱後才能使用。
