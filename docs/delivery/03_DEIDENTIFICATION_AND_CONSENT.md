# 3. 去識別化與資料授權檢查（草案）

> 本文件為**草案**，用來提醒應確認的事項，不構成法律意見。
> 實際的授權書、保密條款與個人資料處理方式，請由律師或法務專業人士審閱。

## A. 去識別化（客戶交付資料前完成）

| 檢查項目 | 做法 | 完成 |
|---|---|---|
| 客戶名稱 | 刪除；客戶代碼改成代號（例如 C-001），對照表留在客戶端 | ☐ |
| 聯絡人、電話、Email、地址 | 刪除整欄 | ☐ |
| 供應商名稱 | 刪除；供應商代碼可改成代號 | ☐ |
| 品名 | 視需要改成類別描述 | ☐ |
| 員工姓名（建檔人員、業務人員等） | 刪除整欄 | ☐ |
| 備註、付款條件等與計算無關的欄位 | 刪除 | ☐ |
| 數量、單價、成本 | **不要更改**，否則驗算沒有意義 | ☐ |
| 隱藏工作表、隱藏欄、註解 | 檢查並清除 | ☐ |
