# 實際限制清單

截至 PR #27（2026-11-04）。以下都是目前程式**確實不做**或**尚未驗證**的事項，對客戶說明時請以本表為準。

## 資料與計算

| 項目 | 限制 |
|---|---|
| BOM | 只支援單階、已展開；單一工廠、單一 BOM 版本 |
| 幣別 | 只用 TWD；外幣一律不可比較，不查、不推測匯率 |
| 稅別 | 只用未稅；含稅或稅別不明的歷史報價不可比較，不自動換算 5% 營業稅 |
| 單位 | 不做任何單位換算；成本以每件（pcs）計算，其他計價單位不提供安全底價 |
| 計價數量 | 每百件、階梯價格不換算，一律阻擋 |
| 成本口徑 | 人工、製費、其他成本視為固定的每件成本，不隨數量變動 |
| 歷史報價比對 | 只比對成品編號**完全相同**的報價；不推估圖面、材質或製程的相似度 |
| 比較門檻 | 數量 0.5～2 倍、730 天、至少 3 筆、價差 30%，都是**未經客戶驗證的預設值** |
| 成交 | 歷史報價不是成交價；成交狀態未知的報價不算成交；不推估成交率 |
| 版本 | 同一天有多個修訂版本時，不判斷哪一版較新 |

## 報價工作台（PR #21～#25）

| 項目 | 限制 |
|---|---|
| 成本模式 | 「既有完整單件成本」與「明細批次成本」只能擇一，不可混用；既有成本模式**不加**批次費 |
| 數量效果 | 不模擬數量對原料議價、良率、工時、委外價的影響 |
| MOQ | 低於 MOQ 的數量不提供底價 |
| 數量 | 只接受正整數 pcs，一次最多 20 個 |
| 版本比較 | 同一天的版本需由使用者指定先後；單價只在幣別、單位、稅別、數量都相同時比較 |
| 客戶草稿 | 只有一張工作表、一位客戶、一種幣別；沒有公司抬頭或 Logo；價格必須由人填寫；系統不核准、不簽名、不寄送 |
| 上傳時序 | 主頁必須先選擇報告類型；「客戶報價風險報告」在 ③ 上傳完成並可讀取之前不會出現產生按鈕（PR #27）。其他頁面的報告只使用按下按鈕時已上傳完成的檔案，上傳完成後舊結果會自動失效 |
| 草稿與正式報價單 | 系統只產生「未核准草稿」或「價格已人工填寫的報價草稿」，**不產生正式報價單**；正式報價須依公司流程由權責主管核准 |

## 案件工作台（PR #32～#35）

| 項目 | 限制 |
|---|---|
| 使用者 | 單一電腦、單一使用者；**不支援多人**同時寫入；沒有登入、角色、權限 |
| 操作人 | 稽核紀錄的操作人是「人工填寫（未經身分驗證）」，不是電子簽核 |
| 存放位置 | 只能放本機磁碟；不可放網路共享磁碟；路徑必須由使用者明確輸入 |
| 加密 | SQLite 檔案**沒有加密**；需要時使用 BitLocker／FileVault 等磁碟加密 |
| 原始檔 | 不保存上傳的原始 Excel，只保存來源檔名與列號 |
| RFQ | 只支援標準欄名的 `RFQ` 工作表（或經「Excel 欄位對應」轉換）；已存在的案件不會覆寫，整批不保存 |
| 實際成本 | 總成本與明細擇一；明細空白代表未知；成本不完整不計算實際毛利率；數量口徑不同時阻擋，不分攤 |
| 備份 | 由使用者手動建立；沒有排程備份或異地備份 |
| 升級 | 資料結構版本 1；較新版本的資料庫會被拒絕開啟；升級失敗會回滾 |

## 產品範圍

- 不產生對外報價單，不自動寄送，不修改 ERP，不給折扣，不承諾售價。
- 沒有登入與權限。歷史報價每次都要重新匯入標準化檔（不永久保存）。
- 「案件工作台」（PR #32～#35）可選擇在本機 SQLite 保存案件；預設關閉，見下節。
- 沒有 AI 或機器學習；所有判斷都是可逐條檢查的規則。
- 不宣稱支援任何 ERP 的原生匯出格式，也沒有取得任何 ERP 廠商的認證。

## 資安與部署

- 只適合在本機或私有內網執行；沒有 HTTPS 或存取控制，需由公司 IT 另外設定。
- 建議報價報告的 Historical Evidence 含其他客戶的價格，只能內部使用。
- 單檔 20 MB／50,000 列；歷史報價一次最多 20 個檔案、累計 100 MB、累計 100,000 列。
- 50,000 列的成本計算約需 0.7 GB 記憶體、40～50 秒。

## 開發流程

- main 的分支保護（必要 status check `test`、禁止 force push）**尚未設定**，需由 repository 管理者在 GitHub 設定（見 `docs/WORK_LOG.md`）。

## 尚未驗證

- 真實 ERP 匯出資料，以及真實的歷史報價格式
- Windows／macOS Docker Desktop、客戶硬體
- 第一次使用的人能否自行完成操作
- 任何商業成效：節省時間、提升毛利、成交率
- 系統**沒有**通過任何真實 ERP 資料或客戶驗收
