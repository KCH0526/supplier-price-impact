# 實際限制清單

截至 PR #20（2026-11-04）。以下都是目前程式**確實不做**或**尚未驗證**的事項，對客戶說明時請以本表為準。

## 資料與計算

| 項目 | 限制 |
|---|---|
| BOM | 只支援單階、已展開；單一工廠、單一 BOM 版本 |
| 幣別 | 只用 TWD；外幣一律不可比較，不查、不推測匯率 |
| 稅別 | 只用未稅；含稅或稅別不明的歷史報價不可比較，不自動換算 5% 營業稅 |
| 單位 | 不做任何單位換算；成本以每件（pcs）計算，其他計價單位不提供安全底價 |
| 計價數量 | 每百件、階梯價格不換算，一律阻擋 |
| 成本口徑 | 人工、製費、其他成本視為固定的每件成本，不隨數量變動 |
| 歷史報價比對 | 只比對成品編號**完全相同**的報價；不推估圖面、材質或製程的相似度 |
| 比較門檻 | 數量 0.5～2 倍、730 天、至少 3 筆、價差 30%，都是**未經客戶驗證的預設值** |
| 成交 | 歷史報價不是成交價；成交狀態未知的報價不算成交；不推估成交率 |
| 版本 | 同一天有多個修訂版本時，不判斷哪一版較新 |

## 產品範圍

- 不產生對外報價單，不自動寄送，不修改 ERP，不給折扣，不承諾售價。
- 沒有登入、權限、資料庫、歷史紀錄或永久保存；歷史報價每次都要重新匯入標準化檔。
- 沒有 AI 或機器學習；所有判斷都是可逐條檢查的規則。
- 不宣稱支援任何 ERP 的原生匯出格式，也沒有取得任何 ERP 廠商的認證。

## 資安與部署

- 只適合在本機或私有內網執行；沒有 HTTPS 或存取控制，需由公司 IT 另外設定。
- 建議報價報告的 Historical Evidence 含其他客戶的價格，只能內部使用。
- 單檔 20 MB／50,000 列；歷史報價一次最多 20 個檔案、累計 100 MB、累計 100,000 列。
- 50,000 列的成本計算約需 0.7 GB 記憶體、40～50 秒。

## 尚未驗證

- 真實 ERP 匯出資料，以及真實的歷史報價格式
- Windows／macOS Docker Desktop、客戶硬體
- 第一次使用的人能否自行完成操作
- 任何商業成效：節省時間、提升毛利、成交率
