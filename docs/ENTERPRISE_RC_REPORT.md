## 3. 資料保存與安全條件
- 保存**預設關閉**；必須勾選啟用並輸入本機路徑。路徑不可是網路共享磁碟（`\\server\...`、`//server/...` 會被拒絕）。
- 日誌模式 DELETE（不使用 WAL）；重要寫入使用交易，失敗時回滾。
- 不保存上傳的原始 Excel、憑證或額外欄位，只保存允許清單內的欄位與來源檔名、列號。
- 所有修改都需要原因；報價版本與實際成本回填只新增、不覆寫。
- SQLite 檔案**沒有加密**；請放在已啟用 BitLocker／FileVault 的磁碟，並依公司規定保管備份。
- 資料庫與備份檔已列入 `.gitignore`、`.dockerignore`。

## 4. 不支援與未驗證
- **不支援多人**同時使用，也沒有登入、角色、權限；操作人欄位是「人工填寫（未經身分驗證）」，不是電子簽核。
- 尚未用真實 ERP 的 RFQ、成本或實際成本資料驗證；實際成本的口徑（例如是否含管銷、不良重工）需要與每家企業確認。
- 尚未經客戶實際操作驗收；Windows／macOS Docker Desktop 尚未測試。
- 沒有排程備份、異地備份、稽核紀錄防竄改。
- 不寄送報價、不寫回 ERP、不核准價格。
