安裝與使用方式（企業私有版）

企業私有版只應在本機或公司內網執行。請勿將它部署到公開網路。

方式一：Python 3.11

  1. 安裝 Python 3.11 以上版本。
  2. 取得程式後，在程式資料夾建立虛擬環境：python3.11 -m venv .venv
  3. 安裝套件：python -m pip install -r requirements.txt
  4. 啟動：streamlit run app.py --server.address=127.0.0.1
  5. 瀏覽器開啟 http://127.0.0.1:8501。

方式二：Docker

  1. 安裝 Docker Desktop 或 Docker Engine。
  2. 在程式資料夾執行：docker compose up --build
  3. 瀏覽器開啟 http://127.0.0.1:8501。服務只綁定本機，並以非管理員帳號執行。

第一次使用的順序

  1. 先用程式附的合成範例檔操作一次，確認數字和說明文件一致。
  2. 選擇報告類型：成本影響報告，或客戶報價風險報告。
  3. 上傳公司的 Excel；欄位名稱不同時，先用「Excel 欄位對應」頁轉換。
  4. 設定試算日與毛利目標，產生報告並下載。
  5. 由主管人工覆核後，再決定正式售價。

Windows 與 macOS 的 Docker Desktop 尚未經過實機驗證，導入時會一併確認。

本網站的示範資料全部是合成資料；試算結果僅供參考，不是正式報價，也不代表任何企業的真實成本。
